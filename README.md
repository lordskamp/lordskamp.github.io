# lordskamp.github.io

Статичний GitHub Pages-сайт Lordskamp із портфоліо та іграми. Серверні можливості працюють через Cloudflare Worker у `api/kobza-leaderboard-worker.js`.

## Обпресування

`/Zavod/` — довідник налаштувань екструдерів, Сікори та інструментів, план барабанів і журнал метрових позначок пробою. Працює як звичайна сторінка та [Telegram Mini App](https://t.me/obpresyvanya_bot?startapp). В одному плані можна задати кілька проводів, їхні перерізи, кількість жил, кольори та довжини в кілометрах. Кожна довжина повторюється для кожного вибраного кольору. Черга групує жовто-зелені барабани, враховує першу партію для скрутки та дозволяє змінювати порядок перетягуванням або стрілками. Завдання, черга, номери барабанів і пробої зберігаються на пристрої; таблиця й власні заміри — на сервері. Дані: `Zavod/data.js`; формули довжини: `Zavod/core.js`; порядок і підсумки плану: `Zavod/planner.js`.

Записи мають стани «У черзі», «В роботі» та «Готово»; одночасно в роботі може бути один барабан. Готові записи згортаються в окремий список, і лише вони враховуються в доступній довжині для скрутки. Розкривний підсумок показує також очікувану чергу до першої партії. Очищення можна скасувати; порожня черга зберігається після перезавантаження. Кнопка ⓘ відкриває налаштування цього проводу на головному екрані з поверненням до черги.

Джерела, правила черги й невизначені записи описані у [ZAVOD-SOURCES.md](docs/ZAVOD-SOURCES.md), друковані карти — у [ZAVOD-PRINTED.md](docs/ZAVOD-PRINTED.md), підключення Telegram — у [ZAVOD-TELEGRAM.md](docs/ZAVOD-TELEGRAM.md). Перевірка Заводу: `npm run test:zavod`.

## Шифр

Українська гра «Шифр» відкривається за маршрутом `/shyfr/`. Рівні зберігаються по одному JSON-файлу на категорію; кожен запис містить лише `text` і `source`. Інструкції для локального запуску, Cloudflare KV, Telegram Mini App, Stars і BotFather наведені в [`docs/SHYFR.md`](docs/SHYFR.md).

```powershell
pnpm install
pnpm run validate:shyfr-content
pnpm run check:shyfr-duplicates
pnpm run build:shyfr-content-index
pnpm run lint
pnpm run typecheck
pnpm test
pnpm run build
```

Не додавайте bot token, webhook secret, admin token або повний Telegram `initData` до репозиторію.
