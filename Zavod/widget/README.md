# Прототип віджета скрутки

`splice.html` — автономний експериментальний віджет для повідомлення Telegram. У ньому власна цифрова клавіатура, оскільки віджети не підтримують звичайні поля вводу. Позначки пробоїв округлюються вниз до десятків; до завдання на екрані додається 30 м на кожен пробій. Підтримуються до восьми пробоїв. Дані зберігаються локально в конкретному повідомленні на пристрої.

Прототип ще не підключено до надсилання ботом і не перевірено всередині клієнта Telegram. Підтримка надсилання віджета й окремих можливостей залежить від API та версії клієнта. Кнопка відкриття Заводу працює через `TelegramWidget` після натискання у сумісному клієнті. У звичайному браузері файл можна відкрити для попереднього перегляду, але це не перевірка sandbox.
