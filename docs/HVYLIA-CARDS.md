# Картки «Довжини хвилі»

Каталог містить 400 українських карток: звичайний пак — 200, аніме — 100, ігри — 100. Одна картка містить два полюси шкали; конкретну підказку придумує гравець.

## Знайдена база й локалізація

Перевірено 4 жовтня 2026 року:

- [Sejoslaw/wavelength, js/data/spectrums.js](https://github.com/Sejoslaw/wavelength/blob/8d2be119e0d53f658348229e7a627aa3fe447c2c/js/data/spectrums.js) — велика громадська база польських пар. Із неї відібрано та локалізовано 40 коротких зрозумілих шкал для звичайного паку. Громадську базу не позначаємо як офіційну колоду видавця.
- [Ліцензія Sejoslaw/wavelength](https://github.com/Sejoslaw/wavelength/blob/main/LICENSE) — MIT, Copyright (c) 2025 Krzysztof Dobrzyński. Повний текст збережено разом із публічним набором: `content/hvylia/SEJOSLAW-LICENSE.txt`.
- [cynicaloptimist/longwave](https://github.com/cynicaloptimist/longwave) також має багатомовну базу й MIT для проєкту, але колекцію з багатьма впізнаваними картками видавця не імпортовано. [fonse/wavelength](https://github.com/fonse/wavelength), попередній орієнтир механіки та дизайну, не містить загальної ліцензії на свою колекцію.

40 перекладених карток зберігаються в `content/hvylia/community-spectra.js`, мають категорію `community`, стабільні ID `community-01`…`community-40` та позначення джерела `sejoslaw-mit`. Українські формулювання адаптовано для природного звучання.

Решта 160 звичайних карток — раніше створені оригінальні українські шкали про побут, культуру, абсурд, дискусії та стосунки. Їхні ID та порядок збережено.

## Тематичні паки

Аніме та ігри створено українською для цього проєкту; це нові авторські формулювання, а не переклад платних колод Wavelength. Немає скопійованих зображень карток, діалогів чи офіційних ілюстрацій.

Аніме: по 20 шкал про персонажів, світи, сюжет, постановку та фандом. Ігри: по 20 шкал про механіки, світи, персонажів, спільноту й ігровий досвід. Різні компанії можуть давати підказки зі знайомих їм творів: знання одного конкретного серіалу або гри не потрібне для всього паку.

Публічний каталог `content/hvylia/packs.js` містить назви, описи, кількість і ціну. Кожен тематичний пак коштує **150 Telegram Stars**. Купівля відкриває можливість ведучому створювати матчі з цим паком; запрошені гравці можуть приєднатися без окремої купівлі.

Масиви `ANIME_SPECTRA` та `GAMES_SPECTRA` з `api/hvylia-premium-cards.js` призначено для сервера. Вони не входять у збірку браузера або тренувальний режим. Водночас репозиторій сайту публічний: оплата надає доступ до функції мережевої гри, а не обіцянку секретності текстів карток. Доступ у кімнаті перевіряє сервер за реальною покупкою ведучого.

## Перевірки й подальше редагування

`tests/hvylia-content.test.mjs` перевіряє кількість і ціни паків, унікальність ID та шкал, відсутність однакових полюсів, український текст, довжину підписів, ліцензійну атрибуцію і відсутність преміальних колод у графі імпортів браузера.

Нові картки додавайте в кінець відповідної категорії й оновлюйте `count` у каталозі. Не переставляйте наявні рядки: ID використовуються для відстеження вже зіграних карток у кімнаті.
