# Діаметри SIKORA

Перевірено 30.09.2026 за офіційними матеріалами SIKORA, фото лінії та уточненням оператора.

SIKORA — виробник приладів вимірювання й систем керування. LASER Series 2000 вимірює зовнішній діаметр без контакту; XY-моделі вимірюють у двох площинах. ECOCONTROL з модулем SET POINT може підтримувати заданий діаметр через швидкість лінії або оберти екструдера. Модуль Hot/Cold враховує усадку під час охолодження. Наявність цих модулів на конкретній лінії не встановлена.

Джерела:

- [LASER Series 2000 — вимірювання діаметра](https://sikora.net/en/products/laserseries2000/)
- [ECOCONTROL — заданий діаметр і компенсація усадки](https://sikora.net/en/products/ecocontrol/)

На `Zavod/Screen.JPG` показана панель SIEMENS SIMATIC. Біля вимірювальної головки до ванни видно «Гор. Ø»: поле 2,82 мм, окремий «Допуск» 0,10 мм, поточні вимірювання X/Y 2,82 та овальність 0,00. За розміщенням головки й підписом це гарячий зовнішній діаметр. Фото не визначає модель SIKORA й не показує всі сторінки її налаштувань. Ці два поля не можна автоматично ототожнювати з двома числами рукописної таблиці. 2,82 і 0,10 є прикладом із фото, а не значеннями для всіх проводів.

Оператор підтвердив: у першому полі налаштувань він вводить діаметр жили; приклад для ВВГнг-П 3×2,5 — 1,74 мм. Це фактичний діаметр однієї жили. Приклад не замінює початковий практичний запис 1,75 мм для ВВГ 2,5.

У DRAW_1 для ПВ1 1,5 записано 1,37 / 2,85 мм, матриця 2,80 мм. У друкованій карті IMG_3850 номінальний діаметр жили 1,35 мм, виробу з ізоляцією 2,76 мм. Місцевий орієнтир «матриця + 0,15» дає 2,95 мм. Це різні джерела й різні види значень. Різниця сама по собі не доводить помилку в практичному записі.

В опрацьованій офіційній документації немає універсального правила «матриця + 0,15» для налаштувань SIKORA. Формула збережена як місцевий приблизний орієнтир за поясненням оператора. Довідкові номінальні діаметри підписані як номінальні; практичні значення збережені основними. Друге число в рукописах поки відображається як діаметр з ізоляцією згідно з початковим поясненням користувача. Точний підпис другого поля конкретного приладу ще уточнюється. Допуск не прогнозується з діаметра жили або розміру матриці.

Охолодження й усадка можуть пояснювати частину різниці між гарячим налаштуванням та номінальним розміром готового виробу, але конкретна причина відмінностей у рукописах без моделі й налаштувань лінії не встановлена. Практичні числа не змінені на основі цього припущення.
