# Довідка, практика та прогнози

Друковані джерела опрацьовано 30.09.2026; правила роботи й локальний набір замірів уточнено 19.10.2026.

Перелік містить 70 марок і варіантів із 22 друкованих карт: 122 позиції з 15 фотографій IMG_3848–IMG_3862. Джерела: `Zavod/reference-data.js` і `Zavod/catalog-options.js`. Початкові 37 рукописних рецептів та власні заміри збережено. Відсутність рукопису означає, що практичний режим ще не визначений.

Кожне показане значення підписане: **Довідкові**, **Практичні** або **Прогнозовані**. Практика має пріоритет. Приписки на друкованих фото також належать до практичних даних; для них збережено окреме джерело. Номінальний діаметр дроту позначений як довідковий номінальний, а не практична установка Сікори. Плаский інструмент зберігається текстом без втрати розмірів.

Прогноз спирається на фактичні заміри, геометрію та сумісні конструкції жили. Дані різних режимів екструдерів не змішуються. Для розрахованого або запозиченого значення зберігаються джерела, метод та оцінка впевненості. Повторення одного рукописного запису для споріднених марок не додає незалежних замірів. Історичне порівняння методики 02.10.2026 збережено в [ZAVOD-FORECAST-CHECK.md](ZAVOD-FORECAST-CHECK.md); його числа не слід використовувати як поточні налаштування.

Практичні значення не замінюються розрахунком. Наявні довідкові та прогнозовані числа показані нижче для порівняння, а порожні другорядні джерела приховані. Таблиця має один рядок на марку, розмір і режим та малу позначку джерела під кожною цифрою. Збіг із практикою позначено «підтверджено». Прогнозовані числа ще не перевірені на лінії та не визначають технічних меж обладнання.

Для всіх металевих проводів **чорний і жовто-зелений завжди використовують два екструдери**. Інші кольори дозволяють явний вибір одного або двох; H*/ПВ* початково використовують один, решта марок зберігають встановлений початковий режим. У ПВ3 початкові рукописні режими збережені окремо: 0,75 мм² — 68 або 65/85 при 350 м/хв; 4 мм² — 74 або 64/80 при 150; 6 мм² — 67 при 120 або 64/84 при 130. Нові адмінські заміри мають пріоритет над відповідним старим записом. Джгути відокремлені від металу й завжди працюють одним екструдером без барвника.

Швидкості: **1 — запуск 80 м/хв**, якщо робоча понад 200, і **40 м/хв** за меншої; нижче 40 запуск не перевищує робочу. **2 — округлена проміжна**, **3 — робоча**. Наприклад, робоча 275 → 80 / 180 / 275; 550 → 80 / 320 / 550. Робочу швидкість можна змінити на головному екрані. Для того самого проводу, геометрії та режиму кожен RPM множиться на відношення нової швидкості до початкової: **60/100 при 250 → 72/120 при 300**, без обрізання різниці до 40. Найбільша відома швидкість показана як довідка про записи, а не як непідтверджена фізична межа.

Орієнтири майстра для **барвника №2** приблизні: клас 5 — 1900 / 1600 / 1200 м для 1 / 1,5 / 2,5 мм²; клас 1 — 1900 / 1600 м для 1,5 / 2,5 мм². Власний практичний замір має пріоритет. Орієнтири не є калібровкою RPM і не переносяться на №1. Подробиці та межі наближення: [ZAVOD-ADMIN.md](ZAVOD-ADMIN.md).

Локальний набір для першого запуску без зв’язку містить 11 публічних числових замірів для 7 марок/варіантів, отриманих 19.10.2026, без приватних приміток. Після успішного оновлення повний серверний набір та його видалення мають пріоритет.
