Кожне показане значення підписане: **Довідкові**, **Практичні** або **Прогнозовані**. Практика має пріоритет. Приписки на друкованих фото також належать до практичних даних; для них збережено окреме джерело. Номінальний діаметр дроту позначений як довідковий номінальний, а не практична установка Сікори. Плаский інструмент зберігається текстом без втрати розмірів.

Прогноз потребує щонайменше двох незалежних практичних перерізів у сумісному режимі тієї самої групи карт. Робоча швидкість розраховується за співвідношенням практичної та довідкової швидкості. Оберти враховують цю швидкість і різницю між практикою та довідкою; за відсутності довідкових обертів використовується площа ізоляції. Між відомими перерізами коефіцієнти інтерполюються, за межами діапазону береться найближчий коефіцієнт. Повторення одного рукописного запису для споріднених марок не додає незалежних замірів.

Практичні значення показані головними; нижче завжди є довідкові та доступні прогнозовані для порівняння. Збіг із практичним значенням позначено «підтверджено», число повторно не показується. Якщо власний частковий замір містить робочу швидкість, прогнозовані оберти перераховуються на неї. Різні напруги, класи жили та карти не об’єднуються без підтвердження; напругу прибрано лише з видимих назв. За відсутності достатньої практики прогноз порожній, а довідкові дані доступні. Прогнозовані числа ще не перевірені на лінії та не визначають технічні межі обладнання.

ПВ3: оператор підтвердив один екструдер для суцільного кольору, два для жовто-зеленого (жовта основа та зелені смуги). Для 0,75 мм²: 68 або 65/85 об/хв, робоча швидкість 350 м/хв. Для 4 мм²: 74 або 64/80, швидкість 150. Для 6 мм²: 67 при 120 м/хв або 64/84 при 130 м/хв. Пари 50/130 для 1 мм² та 80/100 для 2,5 мм² застосовано лише до двох екструдерів. Прогнози калібруються окремо для кожного режиму; застосований замір не видаляє початкових значень іншого режиму. Невизначені додаткові 57 і 300 у рядку 0,75 збережено в примітках до фото. Таблиця містить 383 поєднання марки й перерізу, 390 профілів із двома режимами ПВ3.

Швидкості: **1 — запуск 20 м/хв**, **2 — приблизно половина робочої, округлена вниз із кроком 20 м/хв**, **3 — робоча**. Наприклад, 275 → 120, 325 → 160, 550 → 260. Друга швидкість не нижча за запуск і не вища за робочу. Поля введення швидкості в калькуляторі немає. Колір змінює оформлення й барвники; числові налаштування всередині одного режиму від кольору не залежать. Вибір жовто-зеленого ПВ3 перемикає режим на два екструдери. Біла основа показується білим блоком першого екструдера лише при роботі двох екструдерів. Один екструдер має загальний колір сторінки.
