# Довжина хвилі

Командна браузерна гра українською за адресою `/hvylia/`. Потрібні щонайменше чотири гравці: по двоє в кожній команді. Гравці входять із нікнеймом, без реєстрації. Ведучий створює кімнату, ділиться посиланням, розподіляє команди й запускає матч.

## Архітектура

Сайт залишається статичним GitHub Pages-проєктом на HTML, CSS та JavaScript. Гра має окремий каталог `hvylia/` та посилання в наявному списку проєктів. Вона використовує Inter і власну стриману композицію зі спектром у центрі. Наявні ігри та серверні маршрути не потребують змін.

Синхронізацією керує окремий Cloudflare Worker `dovzhyna-hvyli`, точка входу — `api/hvylia-worker.js`, конфігурація — `wrangler.hvylia.jsonc`. Кожна кімната працює в окремому Durable Object. Він послідовно обробляє дії, зберігає стан кімнати у власному сховищі та надсилає персональні оновлення через WebSocket. Нова база даних, Redis, сервер авторизації або акаунти гравців не потрібні. Чисті правила й перевірки ролей — у `api/hvylia-core.js`, їхні тести — у `tests/hvylia-core.test.mjs`.

Клієнт відправляє наміри: пересунути стрілку, подати підказку, зафіксувати відповідь, обрати сторону. Сервер перевіряє фазу раунду, команду, роль та актуальність дії. Рахунок, черга ходів і завершення матчу обчислюються на сервері.

До відкриття цілі її позиція входить лише до повідомлення поточного Телепата. Інші гравці не отримують її ні в lobby, ні під час руху стрілки, ні при повторному підключенні. Після відкриття позиція стає доступною всім учасникам. Нікнейми й текстові підказки відображаються як текст.

## Локальний запуск

```powershell
pnpm install
pnpm run dev:hvylia
```

Відкрийте `http://localhost:8787/hvylia/`. Цей запуск обслуговує і статичну гру, і локальний Worker, тож WebSocket працює на тому самому origin через `/api`. Команда збирає статичні файли перед стартом; після зміни файлів перезапустіть локальний запуск. Для окремих гравців використовуйте різні профілі браузера або приватні вікна: дві вкладки з одним токеном повернення представляють одного гравця.

Перед публікацією:

```powershell
pnpm run lint
pnpm run typecheck
pnpm test
pnpm run build
```

Повна ручна перевірка потребує чотирьох незалежних клієнтів: створення кімнати, приєднання за посиланням, команди 2 × 2, підказка, рух стрілки, фіксація, ставка суперників, відкриття, наступний раунд і завершення матчу. Окремо перевірте перезавантаження сторінки, втрату зв’язку, вихід ведучого та Телепата. На телефоні перевірте дотик і перетягування; на клавіатурі — Tab і стрілки. Наявність пункту в цьому переліку сама по собі не означає, що конкретний браузер уже перевірений.

## Публікація

Гра має ізольовану конфігурацію Cloudflare, тому її розгортання не змінює Worker інших ігор. Із чинною авторизацією Cloudflare у цьому проєкті:

```powershell
pnpm run deploy:hvylia
```

Публічна адреса Worker: `https://dovzhyna-hvyli.lordskamp.workers.dev/hvylia/`. Worker також віддає файли гри, тому її можна відкрити на цій адресі. Команда розгортання створює прив’язку Durable Object і застосовує міграцію з `wrangler.hvylia.jsonc`; не потрібно вручну створювати KV namespace або переносити секрети інших ігор.

Для основної адреси `https://lordskamp.github.io/hvylia/` опублікуйте змінені статичні файли звичайним способом GitHub Pages. Її клієнт підключається до API, заданого в meta-тезі `hvylia-api-endpoint`: `https://dovzhyna-hvyli.lordskamp.workers.dev/api`. На самому Worker і локальному сервері використовується `/api` того самого origin. Доступність основної адреси залежить від обох публікацій: GitHub Pages віддає інтерфейс, а Worker підтримує кімнати й WebSocket. Перевіряйте створення кімнати після обох розгортань; сама наявність статичної сторінки не перевіряє multiplayer.

`scripts/hvylia-build.mjs` готує `outputs/hvylia-site` зі статичними файлами гри та favicon для Cloudflare Assets. Зміни в цьому згенерованому каталозі не є джерелом інтерфейсу; редагуйте файли в `hvylia/`.

## Кімнати та повернення до гри

Код кімнати складається з чотирьох великих літер або цифр без неоднозначних символів. Посилання із lobby містить код, але не містить персонального токена повернення. Нікнейми в кімнаті мають бути різними.

Персональний токен зберігається в `localStorage` лише для повернення до своєї кімнати після перезавантаження. Стан гри не синхронізується через `localStorage`: клієнт щоразу отримує його із сервера. Постійний токен передається в заголовку `Authorization: Bearer` до `/resume` і `/socket-ticket`. WebSocket відкривається з одноразовим ticket, що діє 30 секунд; постійний токен не включається в URL. Відкриття тієї самої кімнати з токеном в іншій вкладці замінює попереднє з’єднання, щоб дві вкладки не керували одним гравцем одночасно.

Після виявленого відключення є 30 секунд на повернення. При обриві без повідомлення про закриття сервер спершу виявляє втрату heartbeat, що може зайняти до 65 секунд. Після пільгового часу він відновлює можливість продовжити гру: передає роль ведучого доступному учаснику та обробляє відсутнього Телепата. Якщо в команді недостатньо доступних гравців, гра очікує відновлення складу замість прийняття дій у неможливому стані. Видалений ведучим учасник не може повернутися зі старим токеном.

TTL кімнати — 24 години від останньої активності підключених учасників. Durable Object очищує прострочений стан; клієнт пояснює, що кімнату закрито, і дає створити нову. Завершені матчі не архівуються назавжди.

## Правила й налаштування

Активна команда ставить стрілку після текстової підказки Телепата. Телепат не керує стрілкою. Після фіксації суперники обирають, ліворуч чи праворуч від стрілки лежить центр цілі. Підтверджена дія змінює фазу на сервері й не може бути повторно зарахована.

Базовий рахунок на шкалі 0–100: 4 очки за відстань від центру до 2 включно, 3 — до 6, 2 — до 10, далі 0. Сектори симетричні, а їхні межі включені до ближчого сектора. За правильну сторону суперники отримують 1 очко; якщо активна команда набрала 4, цього бонусу немає. Звичайна межа перемоги — 10 очок, її можна змінити в lobby в межах 5–30. Якщо команда влучила на 4, але досі програє, вона отримує ще один хід з іншим доступним Телепатом. Нічия на переможній межі переводить гру в додаткові раунди; переможець визначається, коли рахунки стають нерівними.

Геометрія секторів, межа перемоги та правила переходів винесені з інтерфейсу в `GAME_CONFIG` і чисті функції `api/hvylia-core.js`. Стандартні затримки відкриття — 700 мс, показу результату — 1200 мс; максимум 24 гравці, нікнейм до 24 символів, підказка до 120. Перед стартом у кожній команді мають бути принаймні два підключені гравці, які позначили себе готовими. Для зміни режиму редагуйте параметри та перевіряйте тести правил, а не лише підписи на екрані.

## Власні спектри та локалізація

`content/hvylia/spectra.js` містить 160 оригінальних українських спектрів: по 32 побутових, культурних, абсурдних, дискусійних і про стосунки. `SPECTRA` — заморожений масив записів `{ id, left, right, category }`; кожен запис також заморожений. Контент не залежить від ігрових правил.

Додавайте пари в кінець відповідної категорії, зберігаючи порядок наявних записів: номер у категорії входить до стабільного ID. При створенні нового набору використовуйте нову назву категорії. Полюси мають задавати зрозумілий напрямок шкали та залишати простір для різних підказок. Не додавайте картки, ілюстрації, логотип або фірмові матеріали Wavelength.

Видимі ігрові рядки зібрані в окремому словнику української локалізації `hvylia/locale.js`. Нові мови додавайте через словник та вибір локалі, зберігаючи внутрішні назви ролей і фаз. На головній сторінці назва «Довжина хвилі» зберігається українською в обох мовних режимах сайту.
