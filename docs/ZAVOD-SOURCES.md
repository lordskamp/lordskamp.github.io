# Аудит джерел для ділянки обпресування

Дата транскрипції: 29.09.2026. Основні дані: [Zavod/data.js](../Zavod/data.js).

Рукописні експериментальні дані мають пріоритет за вказівкою користувача. Усі DRAW_1…DRAW_6 та IMG_3843 переглянуто безпосередньо. Порожня клітинка сама по собі не означає 0 або вимкнений екструдер. Для ПВ1 1,5/2,5 та ПВ3 0,5/1,5 користувач 29.09.2026 підтвердив роботу лише першим екструдером; це позначено `mode: single`, E2 залишено `null` відповідно до порожньої клітинки джерела. Неоднозначні робочі значення в даних позначено `null`; буквальний запис збережено у примітках. Стовпець `mode: unknown` вимагає уточнення режиму, а не автоматичного вибору одного екструдера.

Позначення автора: д — дорн, м — матриця, 1/2 — продуктивність екструдерів, V/шв — максимальна швидкість, ф — переріз у мм². Значення продуктивності переписані як числа установки; одиниці в рукописних таблицях не вказано. Два числа Sikora збережено окремо.

В інших рядках є одна колонка V, спільна для режимів; якщо буде окремий практичний замір, він матиме пріоритет. ## Відмінності від приблизної формули Sikora

Користувач пояснив друге значення як приблизно «матриця + 0,15». Частина експериментальних записів відрізняється. `data.js` зберігає саме рукописне значення; формула повинна показуватися окремо як розрахунок, якщо її використовує інтерфейс.

Приклади: ПВ1 1,5 — 2,85 при матриці 2,8; YSLY/H05VV-F 1 — 2,12 при матриці 2,1; ПВ3 1 — 2,5 при матриці 2,2; H05VV-F 1,5 — 2,98 при матриці 2,8. Це не округлення єдиної точної формули.

## Пояснення користувача поза фотографіями

- При закінченні вхідного барабана додати 30 м до відповідної довжини на екрані; на листку зафіксувати місце пробою, яке покаже обладнання.
- Загальний орієнтир зміни барвника другого екструдера — близько 2000 м до кінця; залежить від продуктивності. Орієнтир першого — близько 300 м. Точних залежностей у джерелах немає.
- Для ручного перекидання після зміни кольору: довжина завдання мінус 150 м у ванні плюс 1000 м запасу, який не дає автоматично перекинути барабан. Для 15000 м приклад дає 15850 м. Фактичний момент ручного перекидання визначається появою потрібного кольору на четвертому ряду ванни.
- Перший екструдер — основа, переважно біла; для жовто-зеленого в першому вмикають жовтий барвник. Другий — верхній шар. Для підтверджених режимів одним екструдером усі барвники використовуються в першому.

Ці правила походять із повідомлення користувача, а не з друкованої інструкції. Приблизні відстані не слід показувати як гарантовані результати. Порожні режими не доповнюються значеннями з інших марок чи перерізів.
