# Таблиця та заміри

Сайт: https://lordskamp.github.io/Zavod/

Адмін-панель: https://t.me/obpresyvanya_bot?startapp=admin

## Як записати замір

1. Відкрити застосунок через Telegram-акаунт **@Lordskamp** → **Адмін**.
2. Форма відкриється для проводу й перерізу з головного екрана. За потреби змінити їх. Форма підставить відомі практичні значення; режим визначається автоматично за введеними обертами. Довідка й прогноз не записуються як замір.
3. Вписати перевірені числа та, за потреби, примітку.
4. Натиснути **Зберегти замір**. Запис з’явиться у **Попередніх замірах**.

Кожен збережений адмінський замір доступний усім як **Практичні** числові значення та уточнює прогноз. Це стосується й попередніх записів, які раніше залишалися лише в журналі. Примітки й дані акаунта не публікуються. Значення спільні для всіх кольорів з однаковою кількістю увімкнених екструдерів. Для марок **H*** (також **(H)**) та **ПВ*** синій і жовто-зелений працюють двома екструдерами; інші кольори, включно з чорним, за замовчуванням одним. Для решти марок збережено раніше встановлені режими. Налаштування **тільки №1** та **№1 + №2** зберігаються окремо; колір визначає режим і схему подачі барвників.

Порожнє поле означає «не записано», а не нуль. **0** в обертах №2 означає вимкнений другий екструдер та режим **тільки №1**. Одне додатне число у №1 з порожнім №2 також визначає роботу одним екструдером. Два окремі додатні числа або пара **53,7/72,2** визначають роботу двома. Якщо у першому полі **75**, а у другому **53,7/72,2**, зберігаються два незалежні набори обертів: один екструдер — 75; два — 53,7 і 72,2. За такого вводу решта полів належить режиму двох екструдерів; окремий режим одного отримує лише явно введені оберти. Вибір кількості екструдерів із форми прибрано. Пара має містити два додатні числа; вимкнення №1 при працюючому №2 потребує окремого режиму, якого установка тут ще не описує.

Частковий застосований замір зберігає раніше виміряні непорожні поля того самого проводу, перерізу й режиму незалежно від кольору. Зміна обертів автоматично уточнює режим, залишаючи введені поля на місці. Незавершені чернетки для вибраного проводу й перерізу відновлюються з їхнім введенням. Кнопка **Новий замір** починає свіжий запис із практичних значень. Випередження зміни барвника №1 і №2 задаються окремо цілими невід’ємними метрами; для одного екструдера поправка барвника №2 вимкнена. План використовує ці практичні поправки автоматично, а для незаписаних полів — загальні поправки плану.

Чернетки зберігаються на пристрої окремо для різних проводів, перерізів і режимів екструдерів. Старі чернетки з поділом за кольором також доступні. Після помилки зв’язку повторне збереження не дублює запис. Якщо змінилася версія таблиці, кнопка **Оновити таблицю для повторного збереження** збереже введене у формі. Після явного оновлення й повторного збереження конфліктного режиму створюється актуальний замір; попередній запис залишається в історії зі своєю датою. Уже успішно збережений інший режим не повторюється. Незавершений запис повторно перевіряється перед застосуванням: якщо стара версія сервера пропустила поле, повідомлення пояснить відмінність, а явне оновлення дозволить зберегти всі введені значення як новий замір.

**Таблиця → Фото** показує довідку, практичні записи й пояснення. Власнику також доступна **Історія змін**. Старі заміри можна взяти за основу нового. Заміри доступні для кожної марки з друкованої довідки, навіть якщо рукописного запису ще немає.

У **Попередніх замірах** кнопка **Видалити** прибирає запис із журналу та прогнозу. Якщо він був поточним налаштуванням, сервер повертає попередній застосований замір того самого режиму, або початкові дані, якщо попереднього немає. **Повернути видалений замір** відновлює його лише в журналі; для повторного використання треба взяти його за основу й застосувати знову.

План барабанів зберігається на пристрої. Заміри та робоча таблиця — на сервері, спільно для телефона й комп’ютера. Для редагування з комп’ютера також треба відкрити Mini App у Telegram.

Угорі плану барабанів є окремий, за замовчуванням згорнутий модуль **Планування скрутки**. Вкажи потрібну довжину та накопичувальні позначки пробоїв через кому. Результат одразу з’явиться під полями. Можна дописувати кілька пробоїв; також підтримуються «;» і нові рядки. Позначки округлюються вниз до десятків, відрізки записуються без запасу: 15 000 м і пробій 6838 → **(6830+8170)**, на екрані **15 030 м**. Пробої 5385 та 8459 → **(5380+3070+6550)**, на екрані **15 060 м**. По 30 м за кожне з’єднання додається лише до завдання на екрані; на лейбл ці метри не потрапляють.

Модуль має власну чернетку на пристрої. Чотири пункти розміщені окремими рядками: потрібна довжина, пробої, записати на лейбл і ввести на екрані. Поля введення однакової висоти. Рядки результату завжди видимі, навіть для довжини менше 10 м або некоректного вводу; якщо розрахунок неможливий, показано «—» і пояснення. Провід, колір, переріз, порядок і стан барабанів, очищення черги та її поправки не впливають на цей розрахунок. Повторні після округлення та позначки за межами довжини потребують виправлення.

## Прогноз і планування

Для кожного поля спочатку показано практичне значення; якщо його немає — довідкове, а за відсутності обох — **Прогнозовані**. Виняток для робочих налаштувань: якщо є адмінські заміри швидкості щонайменше для двох перерізів тієї самої марки й режиму, власний прогноз обертів і робочої швидкості має пріоритет перед друкованими максимальними значеннями. Довідкові числа залишаються нижче для порівняння. Так оберти не збільшуються до довідкового максимуму замість виміряної робочої швидкості. Це спільне правило для всіх марок; точні практичні значення збережені. У таблиці один рядок на марку, переріз і режим; джерело підписано під кожною цифрою. Порожні другорядні джерела не відображаються.

Номінальний діаметр ізольованої жили в довідковій карті не є налаштуванням другого поля SIKORA. Він залишається окремим порівнянням, а за відсутності практичного значення SIKORA прогнозується від вибраної матриці з додатною поправкою. Середній орієнтир оператора для 2,5 мм² — +0,15 мм; для тонших жил початкова поправка зменшується пропорційно квадратному кореню від перерізу (наприклад, 1,5 → +0,12 мм, 0,5 → +0,07 мм). Для більших перерізів без додаткових замірів базова поправка залишається +0,15 мм. Власні позитивні пари «SIKORA − матриця» уточнюють її; за їх відсутності використовуються сумісні заміри схожих кабелів. Це практичний орієнтир цієї лінії. Точне практичне значення не перезаписується розрахунком; плоскі парні розміри зберігаються як у довідці.

У компактній формі адміна спочатку йдуть оберти №1/№2 з короткою підказкою, потім SIKORA та дорн/матриця, далі зміна барвника. Поля №1 і №2 розміщені у відповідних стовпцях, введення — у цілих метрах. Робоча швидкість розміщена нижче на всю ширину двох стовпців. Примітка згорнута, поки вона не потрібна; довгі пояснення з форми прибрано.

Нові адмінські заміри мають пріоритет за датою збереження; повторне застосування старого запису не робить його новішим. Частковий замір зберігає попередні непорожні поля. Видалені та повернуті без повторного застосування записи не використовуються. Різні маркетингові назви мають власні практичні налаштування, а запозичені дані позначаються тільки як прогноз.

Для прогнозу спорідненості враховуються режим екструдерів, клас і конструкція жили, геометрія та ізоляція. H05V-K/H07V-K мають близьку конструкцію класу 5 ([H05V-K](https://products.lappgroup.com/online-catalogue/power-and-control-cables/control-cabinet-single-cores/various-applications/h05v-k.html), [H07V-K](https://products.lappgroup.com/online-catalogue/power-and-control-cables/control-cabinet-single-cores/various-applications/h07v-k.html)). ПВ3 та H07V-K мають різні класи 3/4 і 5; схожі розміри дозволяють слабше запозичення для прогнозу, але не перетворюють одну марку на практичний замір іншої ([каталог Interkabel](https://interkabel.ua/wp-content/uploads/01_%D0%A3%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BE%D1%87%D0%BD%D1%8B%D0%B5-%D0%BF%D1%80%D0%BE%D0%B2%D0%BE%D0%B4%D0%B0-%D0%9F%D0%921-H07V-U-H07V-R-%D0%9F%D0%923-H07V-K-%D0%9F%D0%9F%D0%92-%D0%90%D0%9F%D0%92-%D0%90%D0%9F%D0%9F%D0%92.pdf)). Подвійні плоскі конструкції відокремлено від круглих жил.

Між виміряними перерізами використовуються власні практичні значення. За їхніми межами розміри уточнюються за геометрією й відхиленням власних замірів, швидкість — за навантаженням схожих практичних серій, оберти №1 — за площею ізоляції та швидкістю, №2 — за окремою практичною кривою. Друковані оберти й швидкості не використовуються як навчальні заміри. Коли відома швидкість опорного заміру, прогнозовані оберти перераховуються до робочої швидкості, показаної на екрані. Якщо сумісна споріднена адмінська серія має щонайменше два перерізи, її прогноз робочої швидкості й обертів застосовується разом, без збільшення до друкованого максимуму. Для розрахованої пари діє межа **№2 ≤ №1 + 40 об/хв**. Введені й довідкові пари не переписуються; більша різниця пояснюється в розділі джерел.

Початкова локальна таблиця містить публічні числові заміри H07V-K 1,5 / 2,5 / 6 мм² для двох екструдерів станом на 02.10.2026. Вони дозволяють отримати ту саму практичну криву на новому пристрої без Cloudflare. Приватні примітки не включено. Після успішного оновлення повна серверна таблиця та її видалення мають пріоритет; збережена копія використовується без зв’язку.

На головному екрані натисни робочу швидкість, щоб змінити її й попередньо побачити оберти. Вибір зберігається тільки на цьому пристрої для марки, перерізу й режиму екструдерів та застосовується також у черзі. Адмінські заміри залишаються початковими. **Повернути початкову** скидає ручний вибір. Межа введення — найбільша відома довідкова або практична швидкість цього проводу. Кожна зміна рахується від початкової пари, без накопичення попередніх коефіцієнтів.

Такий перерахунок наближено зберігає подачу для незмінної геометрії: нові оберти = початкові оберти × нова швидкість / початкова швидкість, з обмеженням різниці двох екструдерів. Між різними перерізами ця пропорція сама по собі непридатна: потрібна також площа ізоляції й калібрування за замірами. [Технічний посібник HMEL](https://www.hmel.in/assets/pdf/technical_guide_to_wire_and_cable_extrusion_process_%26_polysure_products-final_small.pdf) підтверджує залежність розміру ізольованого проводу від матриці, швидкості протягування й обертів шнека; він не задає точну формулу для цієї установки. Вплив конкретного принтера ще не підтверджено, тому загальну межу швидкості через принтер не введено.

У полі довжин завдання символ **\*** під час введення чи вставлення автоматично перетворюється на **×**; позиція курсора зберігається.

[Контрольне порівняння для H07V-K 6 мм²](ZAVOD-FORECAST-CHECK.md): у прогноз передано власні заміри 1,5 та 2,5 мм², без заміру 6 мм². Цей приклад використано для вибору методики; його похибка не є незалежною оцінкою всіх майбутніх прогнозів.

Перед зміною кабелю або перерізу завдання зупинки зменшується на довжину ванни: за замовчуванням 15 000 → 14 850 м. Резерв зміни барвника тоді не додається. При зміні кольору на тій самій жилі в черзі видно формулу **довжина − 150 + 1000**, а також моменти зміни барвника: за замовчуванням №2 за 2000 м, №1 за 300 м до кінця, якщо його колір змінюється. Для 15 км це екран 15 850 м і позначки 13 000 / 14 700 м. Зміна розсікача або режиму після переходу потребує зупинки.

Початкове порожнє завдання підставляє провід і переріз із головного екрана. Введені завдання й черга зберігаються. Довжини порожні; приклад показаний лише як підказка. Перша партія для скрутки означає кількість барабанів кожного кольору, які треба підготувати спочатку; позначка терміновості прискорює її отримання. **Готово** залишає барабан на тому самому місці й виділяє рядок кольором кабелю; **Не готово** скасовує позначку. Перетягування доступне для всіх рядків.

Запуск: 80 м/хв за робочої швидкості понад 200; 40 м/хв за меншої. Для швидкостей нижче 40 запуск не перевищує робочу. Проміжна сходинка — округлене число між запуском і робочою.

## Дані та доступ

- Перелік: 70 марок і варіантів із друкованої довідки, 122 довідкові позиції. Початкові 37 рукописних рядків із `Zavod/data.js` та власні заміри збережені. Пропуски в оригінальних джерелах зберігаються; прогноз заповнює їх окремо з позначкою джерела.
- API: `https://zavod-data.lordskamp.workers.dev`; налаштування: `wrangler.zavod.jsonc`.
- D1 `zavod-data`: `recipes` — робочі рядки, `measurements` — журнал, `recipe_history` — попередні версії, `settings` — власник.
- Читання робочої таблиці та числових полів усіх збережених невидалених замірів відкрите. Примітки журналу, історія та всі зміни доступні лише власнику. Відновлений видалений запис повертається до розрахунків лише після явного повторного застосування.
- Сервер перевіряє HMAC-підпис Telegram `initData`, термін 12 годин та акаунт. Перший вхід із підписаним іменем `Lordskamp` прив’язує доступ до незмінного числового Telegram ID. Далі збіг імені іншого акаунта не дає доступу.
- Секрет бота зберігається лише як Cloudflare Worker secret `TELEGRAM_BOT_TOKEN`. Клієнт не містить його й не використовує `initDataUnsafe` для авторизації. Підписані дані не записуються в localStorage або журнали сервера.
- Збереження рядка перевіряє версію. Якщо з іншого пристрою вже збережено новіші дані, замір залишається в журналі й формі; повторне застосування потребує явного оновлення версії через кнопку у формі.
- Повторне застосування початкових SQL-записів не перезаписує власні заміри.

## Оновлення

Міграції `0003_measurement_management.sql` та `0004_mode_calibrations.sql` потрібно застосувати **перед** оновленням Worker. Вони зберігають старі записи, відокремлюють маркетингові варіанти й режими екструдерів, додають видалення та об’єднують попередні кольорові налаштування одного режиму. Нову версію сторінки публікувати після оновлення сервера: стара версія API не підтримує нові ідентифікатори й видалення.

07.10.2026 обидві міграції застосовано до виробничої бази, Worker оновлено. Перед зміною створено резервну копію й перевірено перенесення на її локальній копії. Після оновлення підтверджено збереження всіх 9 попередніх замірів та налаштувань власника; публічна таблиця повертає їхні числові дані без приватних приміток.

```powershell
pnpm run test:zavod
pnpm run lint
pnpm exec wrangler deploy --dry-run -c wrangler.zavod.jsonc
pnpm exec wrangler d1 migrations apply zavod-data --remote -c wrangler.zavod.jsonc
pnpm exec wrangler deploy -c wrangler.zavod.jsonc
```

Сайт публікується через GitHub Pages. Інші Worker цього репозиторію використовують окремі конфігурації. Секрети вводити через захищений запит `wrangler secret put`, не додавати їх у Git.

Перевірки: розрахунки довжини, авторизація Telegram, прив’язка власника, відхилення чужих записів, спільні налаштування кольорів одного режиму та незалежність різних режимів, повторне збереження, конфлікт версій, історія та пагінація журналу. Перевірка браузерної форми виконується лише з окремою локальною тестовою базою й тестовим секретом. Вона не створює виробничих замірів.
