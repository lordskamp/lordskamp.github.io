# Обпресування — Telegram Mini App

Сторінка `/Zavod/` працює у браузері й відкривається всередині Telegram як Mini App. Розрахунки виконуються локально, робоча таблиця та журнал замірів зберігаються в Cloudflare D1. Адмін-панель доступна лише власнику через Telegram; див. [інструкцію](ZAVOD-ADMIN.md).

Адреса сторінки: **https://lordskamp.github.io/Zavod/**.

Бот користувача: [@obpresyvanya_bot](https://t.me/obpresyvanya_bot?startapp). Перевірка Telegram Bot API 29.09.2026 підтвердила `has_main_web_app: true` та кнопку меню «Обпресування», що веде на `/Zavod`. Токен не зберігається у проєкті. Створювати нового бота не потрібно; нижче залишено інструкцію на випадок повторного налаштування.

## Підключення окремого бота

1. Опублікуйте сторінку звичайним процесом цього сайту та перевірте, що HTTPS-адреса відкривається з телефона.
2. Відкрийте [@BotFather](https://t.me/BotFather). Створіть окремого бота через `/newbot`, задайте назву, наприклад «Обпресування», і вільне ім’я користувача із закінченням `bot`.
3. Через `/mybots` виберіть створеного бота → **Bot Settings → Configure Mini App → Enable Mini App**. Налаштуйте **Main Mini App** з адресою `https://lordskamp.github.io/Zavod/`, назвою та іконкою. У профілі з’явиться кнопка запуску.
4. Командою `/setmenubutton` виберіть цього бота, адресу `https://lordskamp.github.io/Zavod/` і текст **Обпресування**.
5. Відкрийте створеного бота й запустіть застосунок через кнопку. Для поширення використовуйте `https://t.me/ІМЯ_ВАШОГО_БОТА?startapp`, замінивши ім’я на фактичне.

Токен, який надасть BotFather, не додавайте до HTML, JavaScript, URL або репозиторію. Для наведеного налаштування він не потрібний. Ігровий бот `@unwordle_bot`, згаданий в інших файлах сайту, має окреме призначення.

Кроки налаштування та формат посилань наведено за [офіційною документацією Telegram Mini Apps](https://core.telegram.org/bots/webapps#implementing-mini-apps).

## Інтеграція сторінки

Підключіть офіційний SDK у `<head>` перед модулем застосунку:

```html
<script src="https://telegram.org/js/telegram-web-app.js?63" async></script>
<script type="module" src="./app.js"></script>
```

Сторінка запускає калькулятор незалежно від завантаження SDK й повторює ініціалізацію Telegram після події `load`. Адаптер `Zavod/telegram.js` експортує:

| Функція | Призначення |
| --- | --- |
| `initTelegram()` | Виклик після першого відображення. Повідомляє Telegram про готовність, розгортає вікно, оновлює тему й доступну висоту. Повертає `false` у звичайному браузері. |
| `haptic(kind)` | Вібровідгук: `selection` при зміні варіанта; `success`, `warning`, `error` для результату дії; `light`, `medium`, `heavy`, `rigid`, `soft` для натискання. |
| `openSource(url)` | Відкриває фото або інше HTTP(S)-джерело, зберігаючи калькулятор. Викликати безпосередньо з обробника натискання. |
| `setBackHandler(callback)` | Показує кнопку «Назад» Telegram для відкритого внутрішнього розділу. `setBackHandler(null)` прибирає її. |

Стан Telegram доступний у `html[data-telegram="true"]`; тема — у `data-telegram-theme="light"` або `"dark"`. Адаптер підтримує стандартні CSS-змінні `--tg-theme-*`, `--tg-viewport-height`, `--tg-viewport-stable-height`, `--tg-safe-area-inset-*` та `--tg-content-safe-area-inset-*`. CSS має використовувати резервні значення для браузера. Для елементів унизу екрана використовуйте стабільну висоту; відступи пристрою та інтерфейсу Telegram слід враховувати в компонуванні.

Помилка завантаження SDK або недоступна функція Telegram не зупиняє розрахунки. Адаптер не надсилає результати боту. Для входу в адмін-панель сервер перевіряє підпис `initData`; клієнтське `initDataUnsafe` використовується лише для відкриття потрібного розділу, без надання доступу.

Контракт SDK: [ініціалізація](https://core.telegram.org/bots/webapps#initializing-mini-apps), [безпечні відступи](https://core.telegram.org/bots/webapps#safeareainset), [кнопка «Назад»](https://core.telegram.org/bots/webapps#backbutton), [вібровідгук](https://core.telegram.org/bots/webapps#hapticfeedback).

## Перевірка після підключення

- Відкрийте HTTPS-адресу в браузері без Telegram: вибір проводу, обчислення й фото джерел мають працювати.
- Повторіть ті самі дії через кнопку бота в Telegram на телефоні; значення мають збігатися.
- Перевірте світлу й темну теми, поворот телефона, появу клавіатури та доступність нижніх кнопок.
- Відкрийте фото рукопису, поверніться до застосунку й перевірте, що вибір зберігся.
- Перевірте застосунок при недоступному SDK: сторінка має лишитися придатною для роботи у браузері.
